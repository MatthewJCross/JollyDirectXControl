# Jolly2DBeamRider

Beam Rider demo for the Jolly2D engine using the engine line-rendering path.

## Rendering

The arena perspective beams, scrolling grid, horizon and player ship are submitted as `JollyLineSnapshot` instances through `JollyRenderFrame`.

The demo references `../../Jolly2DEngine/Jolly2DEngine.csproj`.

## Controls

- Left / A: move left
- Right / D: move right
