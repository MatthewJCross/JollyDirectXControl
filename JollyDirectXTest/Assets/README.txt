JOLLY2D ASSET FOLDERS

Textures\   Image assets used by sprites, UI and tile maps.
Audio\      Sound effects and music.
Fonts\      Font files used by game content.
Maps\       Tile maps and world/map data.
Animations\ Animation data and animation-specific assets.

The Phase 13 demo expects these files:

Textures\cheetah.png
Textures\tileset.bmp
Textures\Enabled.png
Textures\over.png
Textures\down.png
Textures\Disabled.png
Textures\round.png
Audio\jump.wav
Audio\unreleased.mp3

Asset names used by the game are relative to these folders. Do not use absolute paths in game code.
The default asset root is the application's Assets folder.
